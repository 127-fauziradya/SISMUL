1. Pendahuluan & Ringkasan Projek

Aplikasi FUNLISH dikembangkan untuk memenuhi kriteria penugasan Kelompok 7, 8, dan 9 mata kuliah Sistem Multimedia, Universitas Muhammadiyah Surakarta (UMS). Fokus proyek adalah membangun media edukasi bahasa Inggris interaktif yang menyenangkan bagi anak SD kelas 3 hingga kelas 6.

Namun, di samping menyajikan portal pembelajaran (kartu kosakata, pengucapan vokal, dan soal kuis), proyek ini diintegrasikan secara penuh dengan **Pusat Pengolahan & Keamanan Multimedia (FUNLISH Studio)** sebagai Teacher Portal. Hal ini bertujuan untuk secara tepat mempraktikkan pengolahan data digital di balik layar aplikasi, yang meliputi:

  1. Kompresi Data (Compression): Untuk mengompres berkas materi (RLE/Huffman) dan kartu gambar (JPEG) sehingga loading aplikasi tetap cepat di jaringan seluler lambat siswa.
  2. Keamanan Data (Security & Steganography): Mengamankan integritas kunci jawaban ujian kuis Kelas 6 dengan Enkripsi XOR biner maupun LSB steganografi di dalam gambar kosakata.
  3. Pemrosesan Sinyal Digital (Signal Processing): Meningkatkan kejelasan vokal rekaman pengucapan kata bahasa Inggris menggunakan filter cutoff frekuensi (Web Audio API), filter spasial gambar (konvolusi spasial), dan Chroma Keying video webcam guru secara real-time.

2. Integrasi Pengolahan Media Teks FUNLISH

A. Kompresi Lossless Run-Length Encoding (RLE)

RLE digunakan untuk memampatkan data teks pelajaran yang berulang. Algoritma ini berjalan dengan merangkum untaian huruf sejenis yang berurutan (run) menjadi huruf tunggal dan frekuensinya (misal: "AAAAABBB" -> "A5B3"). Persamaan hitung rasio penghematan memori ($C_R$) dirumuskan sebagai:

$$C_R = \left( 1 - \frac{\text{Ukuran Terkompresi}}{\text{Ukuran Asli}} \right) \times 100\%$$

B. Kompresi Lossless Huffman Coding

Huffman Coding adalah kompresi entropi berbasis biner variabel-panjang. Setiap karakter unik dalam teks dianalisis frekuensi kemunculannya. Karakter dengan probabilitas kemunculan tertinggi ($P(x_i)$) diberikan kode bit terpendek guna menghasilkan reduksi data biner yang signifikan untuk penyimpanan database materi.

C. Keamanan XOR Kunci Jawaban

Untuk mencegah siswa kelas 6 membobol kunci kuis lewat inspeksi konsol browser, teks kunci dienkripsi menggunakan operasi gerbang logika XOR eksklusif. Persamaan matematika kriptografi XOR dirumuskan:

$$\text{Ciphertext } (C_i) = P_i \oplus K_{(i \bmod L)}$$ $$\text{Plaintext } (P_i) = C_i \oplus K_{(i \bmod L)}$$

Operasi ini bersifat simetris; mengenkripsi ulang ciphertext Hex dengan Kunci ($K$) yang sama akan mengembalikan plaintext ($P$) secara presisi.

3. Pengolahan Media Flashcard Gambar

A. Pemrosesan Citra: Filter Konvolusi Matriks

Aplikasi FUNLISH mengandalkan kartu gambar kosakata (flashcard). Guru dapat memodifikasi citra kartu menggunakan matriks konvolusi spasial $3 \times 3$ yang memanipulasi piksel $g(x,y)$ berdasarkan piksel tetangga $f(x,y)$:

$$g(x,y) = \sum_{s=-1}^{1} \sum_{t=-1}^{1} \omega(s,t) \cdot f(x+s, y+t)$$

Operasi ini meliputi filter Sharpen (menajamkan batas objek kartu), Blur (memotong frekuensi tinggi spasial), dan Sobel Edge Detection (menghitung magnitude gradien horizontal/vertikal citra untuk deteksi tepi).

B. Keamanan: Steganografi LSB (Least Significant Bit)

Steganografi LSB menyembunyikan kunci jawaban kuis di dalam bit terendah (bit ke-0) komponen warna merah piksel gambar flashcard. Perubahan bit 0 ini hanya merubah intensitas warna piksel sebesar $1/255$ tingkat, sehingga perbedaan tersebut tidak tampak secara visual. Format output wajib berupa PNG (lossless) agar bit LSB tidak rusak oleh kompresi warna JPEG.

C. Kompresi JPEG & Watermarking

Penyisipan watermark digital mencegah pencurian kartu kosakata karya sekolah dengan rumus pencampuran linier parameter transparansi $\alpha$ (opacity):

$$O(x,y) = (1 - \alpha) \cdot I(x,y) + \alpha \cdot W(x,y)$$

Sementara kompresi JPEG lossy menurunkan file size kartu gambar secara drastis melalui pengurangan resolusi visual canvas dan penyesuaian kualitas encoding JPEG (1% - 100%).

4. Pengolahan Suara Pelafalan Bahasa Inggris

A. Biquad Filters DSP (Web Audio API)

Kejelasan pelafalan kata bahasa Inggris sangat penting bagi anak SD. Sinyal audio rekaman guru dialirkan secara terarah melalui node BiquadFilterNode untuk pemrosesan frekuensi digital:

  • Low-Pass Filter: Memotong frekuensi di atas batas cutoff ($f_c$), meloloskan bass suara agar terasa penuh.
  • High-Pass Filter: Memotong gemuruh rendah dan kebisingan AC ruangan dari mikrofon guru di bawah $f_c$.
  • Band-Pass Filter: Memfokuskan pita frekuensi sempit khusus vokal manusia.

B. Simulasi Downsampling Kompresi

Simulasi kompresi lossy audio mereproduksi penurunan laju sampel (downsampling) dan kedalaman bit (bit depth) melalui ScriptProcessorNode. Laju sampel dibatasi (misal 44,1 kHz ke 8 kHz) dan amplitudo dikuantisasi (16-bit ke 4-bit) untuk mensimulasikan bitrate terkompresi yang menghemat data seluler siswa.

C. Visualizer Spectrogram & Watermark

Aplikasi menggambar spektrum suara siswa/guru secara real-time di canvas menggunakan algoritma **Fast Fourier Transform (FFT)** dari AnalyserNode. Selain itu, guru dapat menyuntikkan nada sinus 15.000 Hz sebagai watermark audio pelafalan untuk melindungi lisensi suara sekolah.

5. Perekaman Video E-Learning (Chroma Key)

A. Pemrosesan Video Canvas

Untuk membuat materi video pengajaran interaktif, kamera web guru diproses secara frame-by-frame pada canvas penampung dengan frame rate 30 FPS memanfaatkan callback perulangan requestAnimationFrame.

B. Algoritma Chroma Keying

Teknik Chroma Key mengisolasi tirai hijau latar belakang guru. Jarak warna Euclidean piksel $(R_p, G_p, B_p)$ terhadap warna kunci target $(R_t, G_t, B_t)$ dihitung:

$$\text{Jarak Warna } (d) = \sqrt{(R_p - R_t)^2 + (G_p - G_t)^2 + (B_p - B_t)^2}$$

Piksel dengan jarak $d$ di bawah batas toleransi ($T$) akan diset nilai opasitas Alpha channel-nya menjadi $0$ (transparan penuh). Piksel transparan ini kemudian ditumpuk (composited) secara real-time di atas gambar latar kelas virtual kartun FUNLISH yang menarik bagi anak-anak.

6. Buku Manual & Cara Kerja Aplikasi

  1. Portal Siswa (FUNLISH): Siswa memilih kelas belajar. Di Kelas 3, 4, 5, siswa mengeklik flashcard bergambar untuk memicu suara pengucapan bahasa Inggris asli. Di Kelas 6, siswa menjawab kuis pilihan ganda. Kunci jawaban dibaca dan divalidasi langsung oleh biner program.
  2. FUNLISH Studio: Pengelola mengakses menu Lab SISMUL di bagian bawah halaman. Di modul teks, guru mengompres teks atau mengenkripsi kunci XOR. Di modul gambar, guru mengunggah flashcard, menerapkan filter spasial, memasukkan stego, membubuhkan watermark, atau mengompres JPEG. Di modul audio, guru menyaring suara vokal, mengaktifkan downsampling, atau menyalakan watermark audio. Di modul video, guru mengaktifkan kamera web dan menyalakan chroma key.

1. Pengenalan FUNLISH Studio

FUNLISH Studio adalah platform manajemen konten pembelajaran Bahasa Inggris yang dirancang khusus untuk guru SD kelas 3-6. Platform ini dilengkapi dengan teknologi Digital Signal Processing (DSP) untuk pemrosesan audio, gambar, dan teks secara real-time.

Fitur Utama:

  • Kelola Kosakata: Tambah, edit, dan hapus vocabulary dengan emoji dan audio pronunciation
  • Kelola Percakapan: Buat dialog interaktif dengan avatar dan text-to-speech
  • DSP Audio: Kompresi, filter, dan enhance audio pelafalan
  • DSP Image: Pemrosesan gambar kartu kosakata (filter, kompresi, chroma key)
  • DSP Text: Enkripsi jawaban kuis dan kompresi teks
  • 100% Client-Side: Semua pemrosesan dilakukan di browser tanpa perlu server

3. Mengelola Kosakata (Vocabulary)

Menambah Kosakata Baru:

  1. Pilih kelas (3, 4, 5, atau 6) dari Dashboard
  2. Klik tab "Kosakata"
  3. Klik tombol "+ Tambah Kosakata"
  4. Isi form dengan data berikut:
    • Kata (English): Kata dalam bahasa Inggris
    • Arti (Indonesia): Terjemahan dalam bahasa Indonesia
    • Emoji/Icon: Pilih emoji dari grid atau masukkan manual
  5. Klik "Simpan"

Tips: Gunakan emoji yang relevan dengan makna kata untuk memudahkan siswa mengingat vocabulary!

Mengedit atau Menghapus:

  • Klik icon pensil (✏️) pada kartu untuk mengedit
  • Klik icon speaker (🔊) untuk mendengar pronunciation
  • Klik icon hapus (🗑️) untuk menghapus kosakata

4. Mengelola Percakapan (Conversation)

Membuat Dialog Baru:

  1. Pilih kelas dari Dashboard
  2. Klik tab "Percakapan"
  3. Klik tombol "+ Tambah Percakapan"
  4. Isi form dengan data berikut:
    • Dialog (English): Kalimat percakapan dalam bahasa Inggris
    • Terjemahan (Indonesia): Arti dalam bahasa Indonesia
    • Avatar/Emoji: Pilih karakter dari grid atau masukkan manual
    • Speaker: Pilih "Laki-laki" atau "Perempuan" untuk suara
  5. Klik "Simpan"

Info: Dialog akan ditampilkan dalam format chat bubble yang interaktif dengan fitur text-to-speech untuk pronunciation!

5. Fitur Digital Signal Processing

Audio DSP Laboratory:

  • Audio Compression: Kurangi ukuran file audio tanpa mengurangi kualitas signifikan
  • Audio Filtering: Terapkan lowpass, highpass, bandpass filter
  • Echo & Reverb: Tambahkan efek echo untuk latihan pronunciation
  • Pitch Shifting: Ubah nada suara untuk variasi pembelajaran
  • Volume Normalization: Seragamkan volume audio

Image DSP Laboratory:

  • Image Filters: Brightness, contrast, grayscale, sepia, blur
  • Image Compression: Kurangi ukuran file gambar untuk performa
  • Chroma Key: Hapus background hijau untuk green screen
  • Edge Detection: Deteksi tepi objek dalam gambar

Text DSP Laboratory:

  • Text Encryption: Enkripsi jawaban kuis dengan Caesar/Substitution cipher
  • Text Compression: Kompresi teks dengan algoritma Huffman/RLE

6. Tips & Best Practices

Pilih Emoji yang Tepat

Gunakan emoji yang mudah dikenali dan relevan dengan makna kata untuk membantu siswa mengingat vocabulary lebih cepat.

Gunakan Dialog Sederhana

Buat percakapan yang singkat dan mudah dipahami sesuai level siswa SD. Gunakan kalimat yang natural dan sering digunakan sehari-hari.

Tes Audio Pronunciation

Selalu dengarkan hasil text-to-speech sebelum menyimpan untuk memastikan pronunciation yang benar.

Backup Data Berkala

Export data vocabulary dan conversation secara berkala menggunakan browser DevTools (localStorage) untuk backup.

7. FAQ & Troubleshooting

❓ Data hilang setelah refresh browser?

Data disimpan di localStorage browser. Pastikan tidak membersihkan cache/storage browser. Untuk keamanan, selalu backup data.

❓ Audio tidak berfungsi?

Pastikan browser mendukung Web Speech API. Gunakan browser modern seperti Chrome atau Edge. Izinkan permission audio saat diminta.

❓ Bagaimana cara mengganti password?

Saat ini sistem menggunakan hardcoded credentials. Untuk production, implementasikan sistem authentication dengan database.

❓ Emoji tidak muncul dengan benar?

Pastikan menggunakan browser dan OS yang mendukung emoji Unicode terbaru. Alternatif: gunakan input manual dengan emoji keyboard.

❓ Performa lambat saat banyak data?

Batasi jumlah vocabulary per kelas maksimal 50 item. Untuk data lebih besar, pertimbangkan implementasi database server-side.
